# Cinema Guru

A React app to keep track of favorite movies and a "watch later" list,
built as part of the Holberton School curriculum.

## Tech
- React 18 (functional components and hooks only)
- Vite
- React Router, axios, Font Awesome
- Package manager: yarn

## Run locally
1. Start the backend (Docker) so the API runs on http://localhost:8000/
2. Install dependencies: `yarn install`
3. Start the app: `yarn dev`
4. Open http://localhost:3000
